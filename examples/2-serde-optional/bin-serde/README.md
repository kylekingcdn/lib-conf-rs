# `example2-bin-no-serde`

This example highlights consumer integration with serde. 

`serde` support is optional in the library, so we've added the feature flag to enable it.

Aside from that and the missing interval field, this is identical to the `example1` `.env` bin

> [!NOTE]
> The remaining examples will not contain the extra 'noise' fields.
>
> These were provided in the first examples to show the context of
> how `lib-conf` fits into an everyday rust app.
