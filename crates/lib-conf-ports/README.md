## `lib-conf-ports`

Provides `lib-conf` support for 3rd party crate settings

[**crates.io**](https://crates.io/crates/lib-conf-ports)
|
[**Docs**](https://docs.rs/lib-conf-ports/latest)
|
[**GitHub**](https://github.com/kylekingcdn/lib-conf-rs)

## Feature flags

### `default`

No ports are enabled by default.

### `sqlx-postgres`

Enables the [`sqlx::postgres::PgPoolOptions`](https://docs.rs/sqlx/latest/sqlx/postgres/type.PgPoolOptions.html) port, [`PgPoolConfig`](https://docs.rs/lib_conf_ports/latest/lib_conf_ports/sqlx/postgres/struct.PgPoolConfig.html).
